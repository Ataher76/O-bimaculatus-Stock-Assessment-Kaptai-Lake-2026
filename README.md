# Integrated Length-Based Stock Assessment of *Ompok bimaculatus* in Kaptai Lake

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![DOI](https://zenodo.org/badge/1226833832.svg)](https://doi.org/10.5281/zenodo.20030014)

## **Project Overview**
This repository hosts the analytical framework and datasets for a baseline stock assessment of *Ompok bimaculatus* (Butter Catfish) in Kaptai Lake, Bangladesh. As an endangered species with high commercial value, this study utilizes integrated length-based models—**LB-SPR** and **aLBI**—to evaluate the sustainability of the stock under current fishing pressures.

## **Key Research Highlights**
*   **Study Site:** Kaptai Lake, a critical freshwater habitat in Bangladesh.
*   **Assessment Models:** Integrated use of Length-Based Spawning Potential Ratio (LB-SPR) and an advanced Length-Based Indicator (aLBI) framework.
*   **Sustainability Indices:** Calculation of Froese sustainability indicators ($P_{mat}$, $P_{opt}$, $P_{mega}$) and Reference Points ($SPR$, $F/M$).
*   **Major Findings:** 
    *   Stock is overfished ($SPR = 0.30$) with unsustainable fishing pressure ($F/M = 1.32$).
    *   Growth overfishing confirmed ($SL_{50} < L_{50}$).
    *   $100\%$ probability of biomass being below target ($TSB_{40}$) and limit ($LSB_{25}$) reference points.
    *   Recommended minimum size limit: $21.02$ cm ($L_{50}$).

## **Repository Structure**
*   **`/aLBI`**: R scripts and outputs for calculating Froese sustainability indicators and length parameters ($L_{mat}$, $L_{opt}$, etc.).
*   **`/LBSPR`**: R code for Spawning Potential Ratio ($SPR$) estimation and selectivity analysis ($SL_{50}$).
*   **`/Length_Weight_Observation_Data`**: Raw and cleaned length-weight frequency datasets.
*   **`/LWR`**: Length-Weight Relationship analysis scripts.
*   **`/Sensitivity`**: Robustness testing files showing model stability under $\pm5\%$ input variations.
